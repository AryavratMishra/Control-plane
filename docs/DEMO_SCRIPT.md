# ControlPlane 2-minute demo

1. Open the dashboard and explain: "This is an AI Firewall placed before a user can act on an AI response."
2. Run **Safe** → ALLOW. Point out the low scores.
3. Run **Hallucination** → show trusted context contradicting a confident answer → ESCALATE/REPAIR.
4. Run **PII** → show email/phone detection → BLOCK.
5. Run **Cost** → show 5 model calls, 6 tools, 3 retries and 6.8s latency → cost risk.
6. Change a policy threshold and run again to prove governance is configurable.
7. Scroll to Audit Trail and explain that every decision becomes evidence.
8. Close with: "ControlPlane moves AI governance from after-the-fact monitoring to pre-action control."
